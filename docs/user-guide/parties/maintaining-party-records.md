# Maintaining Party Records

Party records represent organizations or individuals that participate in reinsurance contracts.

![Parties page with active party records](../assets/screenshots/parties-page.png)

Party records should be maintained as reusable entities that can be linked to many contracts.

## Edit a party

1. Open the party detail page.
2. Start editing.
3. Update the party fields.
4. Save the changes.

## Common updates

- Name corrections.
- Party type updates.
- Contact email, phone, or address changes.
- Identifier or notes updates.

## Party type and contract role

Party type describes the party record. Contract role describes what that party does on a specific contract. Review both when maintaining data.

## Deleting a party

Deleting a party is a soft delete. Use it when the party should no longer appear as active, but historical associations may still matter.
