# Finding Contracts

Use the Contracts page and Dashboard to find contract records after approval.

![Contract detail page showing status, review status, and associated parties](../assets/screenshots/contract-detail.png)

Contract records show core contract status alongside associated parties and their roles.

## Browse recent contracts

The Dashboard shows recent contract activity and summary counts. Use it for a quick overview.

## Search and filter

On the Contracts page, use available search and filter controls to narrow the list by status or visible text such as contract name or number.

## Open contract details

Select a contract from the list to view:

- Contract fields.
- Associated parties and roles.
- Source document metadata.
- Review status.

## If a contract is missing

Check whether the extraction was approved. Uploaded documents do not become contract records until the review workflow is approved.
