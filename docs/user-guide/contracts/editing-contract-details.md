# Editing Contract Details

Use the contract detail page to correct or maintain contract information after approval.

![Contract detail page with edit action](../assets/screenshots/contract-detail.png)

Open a contract detail page before editing so you can review the current status, type, and party associations.

## Edit a contract

1. Open the contract detail page.
2. Start editing.
3. Update the fields that need correction.
4. Save the changes.

## Common updates

- Correcting dates, limits, retention, or premium.
- Updating status.
- Refining contract type, subtype, or nature.
- Correcting source document metadata.

## Review before saving

For material changes, compare the update against the source document or your internal contract system before saving.

## Deleting a contract

Deleting a contract is a soft delete. The record is marked inactive rather than physically removed from the database.
