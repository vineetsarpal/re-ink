# Approving or Rejecting an Extraction

Approval creates contract and party records from the reviewed extraction. Rejection discards the extraction workflow for that document.

## Approve an extraction

1. Review all contract fields.
2. Review all party fields.
3. Link extracted parties to existing parties when appropriate.
4. Confirm required fields are complete.
5. Select the approval action.

After approval, re-ink creates the contract record and associated party links.

## Reject an extraction

Reject an extraction when the document is wrong, the extraction is unusable, or the upload should not create records.

1. Select the rejection action.
2. Confirm the rejection.
3. Re-upload the correct document if needed.

## Duplicate contract warning

If the contract number already exists, re-ink may block approval to avoid duplicate records. Check the existing contract before deciding whether to update it manually or revise the extracted data.
